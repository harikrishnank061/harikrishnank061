## 🗂 PROJECT SHOWCASE

<details open>
<summary><strong>01 · TraceVision AI — Person Identification System for Video Forensics</strong></summary>

<br/>

**An AI-based identification system for video forensics and surveillance analysis, built to run at scale without GPU dependency.**

**Stack:** Python · MTCNN · SSD · ArcFace · Computer Vision

**Problem:** Manual video forensics review is slow and error-prone at scale, especially across large individual databases and long-form footage.

**Engineering Approach**
- Implemented face detection using MTCNN and SSD.
- Built facial recognition on ArcFace embeddings with cosine similarity matching.
- Designed frame sampling and parallel computation to keep the pipeline efficient.
- Optimized the full pipeline to run on standard CPU hardware.

| Metric | Result |
|---|---|
| Scale | 500+ individuals |
| Processing speed | 15 FPS |
| Identification accuracy | 92% |
| False positives | Under 5% |
| Impact | 3× reduction in video analysis time |

</details>

<details>
<summary><strong>02 · Malicious URL Detection System Using Machine Learning</strong></summary>

<br/>

**A classification system that flags malicious URLs from structural and domain-based signals before they reach a user.**

**Stack:** Python · Machine Learning · Random Forest

**Problem:** Malicious URLs need to be classified reliably and quickly, using signals available without visiting the destination.

**Engineering Approach**
- Extracted structural and domain-based URL features, including WHOIS-related data.
- Engineered 20+ attributes such as URL length and special-character patterns.
- Benchmarked Random Forest against a Logistic Regression baseline.
- Evaluated with precision, recall, and accuracy.

| Metric | Result |
|---|---|
| Dataset | 10,000+ URLs |
| Features | 20+ attributes |
| Accuracy | 96.4% |
| Precision | 95% |
| Recall | 97% |
| Improvement over baseline | 8% |
| Feature engineering gain | 18% signal quality improvement |

</details>

<details>
<summary><strong>03 · Plant Disease Detection System Using Deep Learning</strong></summary>

<br/>

**A transfer-learning based image classifier for identifying plant diseases from leaf photos, delivered through a React interface.**

**Stack:** Python · MobileNetV2 · React.js

**Problem:** Farmers and growers need fast, accessible disease identification without lab-grade equipment.

**Engineering Approach**
- Built a MobileNetV2-based classification model using transfer learning.
- Applied data augmentation to improve generalization and cut training time.
- Classified across 38 plant disease categories from the PlantVillage dataset.
- Delivered a React.js interface for image upload and real-time identification.

| Metric | Result |
|---|---|
| Dataset | PlantVillage — 54,000+ images |
| Classes | 38 disease categories |
| Validation accuracy | 93.5% |
| Impact | 40% reduction in training time |

</details>
